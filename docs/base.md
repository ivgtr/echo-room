# 『ECHO ROOM / 残響室』

## ゲーム概要

**ジャンル:** 一人称短編脱出ゲーム / SFミステリー  
**想定プレイ時間:** 15〜25分  
**舞台:** 地下研究施設の実験室1室＋前室  
**主要ギミック:** 20分先から届く音声通信  
**大きな驚き:** プレイヤーを助けていた「隣室の人物」は、20分後の自分自身

ゲーム中に大きな真相を何重にも重ねない。

最後に、

> 「最初から聞いていた声を、これから自分が録音する」

という一点にすべてが収束する。

---

# 世界観

2039年。

人間の記憶や意識ではなく、**情報だけを短時間だけ過去へ送信する技術**が研究されていた。

東央先端技術研究所の地下施設では、

**ECHO計画**

と呼ばれる実験が行われていた。

実験装置《ECHO BUFFER》が送れるのは映像でも物質でもない。

音声だけ。

そして送り戻せる時間は、

**20分。**

しかし実験中、施設で事故が発生。

自動封鎖システムが作動し、研究員の一人である主人公は実験室に閉じ込められる。

非常電源が尽きるまで、およそ20分。

# プレイ時間設計

| 時間 | 内容 |
|---|---|
| 0〜2分 | 覚醒、通信相手登場 |
| 2〜5分 | 電源パズル |
| 5〜8分 | 時刻ログ・ロッカー |
| 8〜11分 | フロア図から「隣室がない」と判明 |
| 11〜15分 | 音声ログ・声紋解析 |
| 15〜18分 | 「20分後の自分」と判明 |
| 18〜20分 | 過去の自分への音声送信・脱出 |

---

# 謎解き設計の意図

このゲームでは「難しい暗号を解くこと」を目的にしない。

すべての謎を、

**20分の時間差**

という一つのルールを理解するために配置する。

具体的には、

1. 音を使った電源パズル
2. 受信時刻と送信時刻の20分差
3. 未来時刻を使ったロッカー
4. 存在しない「隣室」
5. まだ聞いていない未来の音声
6. 自分自身と一致する声紋
7. 自分が過去へ同じ音声を送る

という順番で、

「変だ」

↓

「未来から来ている？」

↓

「この声は誰だ？」

↓

**「自分だった」**

へ自然に認識を更新させる。

---

# このシナリオで重要な演出

最大のポイントは、序盤の声を**露骨に怪しくしないこと**。

親切で、多少ぶっきらぼうだが普通の人間として演出する。

プレイヤーに、

「こいつが黒幕なのでは？」

と思わせる必要もない。

むしろ、

**普通の協力者だと思わせた方が最後の発見が効く。**

さらに、未来の主人公は万能ではない。

自分自身も20分前に同じ経験をしただけなので、

知っているのは、

**自分が実際に経験した範囲だけ。**

そのためヒント役としても不自然にならない。

---

# 実装時に残すべき伏線

伏線は多くしすぎない。

最低限、この4つで十分。

- すべてのログが正確に20分ずれている
- 通信相手が部屋の構造を妙に詳しく知っている
- フロア図には隣室が存在しない
- 通信相手が一度だけ「前に見たことがある」と言う

これらは初見では流せる。

しかしエンディング後には、

**全部そのまま答えだった**

と理解できる。

---

# このゲームの核

プレイヤーが驚く場面は、

「未来から通信していた」

という説明を読んだ瞬間ではない。

本当に重要なのは最後。

ゲーム冒頭に聞いた、

> 「……聞こえるか？」

という台詞を、

**今度は自分自身が選択して過去へ送信する瞬間。**

そこでプレイヤー自身の操作によって、

冒頭とエンディングが接続される。

つまりこの作品では、

**真相をムービーで見せるのではなく、プレイヤー自身に真相を完成させてもらう。**

そこを最大の見せ場にする。
