# 冒頭と最後を同じ声でつなぐ音声試作

2026-10-02。[Issue #21](https://github.com/ivgtr/echo-room/issues/21)に基づき、字幕のみだった方針を3場面に限って変更する。目的は声を正解条件にすることではなく、冒頭で受け取った声を最後に自分が送る体験を、息づかいと間まで同一の原音で回収することにある。

## 決定

発話対象と演出は`base.md`の音響方針、受け入れ条件は`requirements.md`の11章、単一Sound Manager・静的WAV取得・設定互換性は`technical-design.md`の10章・12章を正本とする。`project-decisions.md`のD-02を含む旧来の発話音声・voice系統の禁止は、この試作範囲で置き換える。制作元と利用条件は`audio/voice/README.md`へ集約し、ここへ複製しない。

終盤では既存文言「……聞こえるか？」を現在側の発話として補い、過去側の「……何だ、ここ……。」「誰だ？」を分離する。ドア解錠は既存実装どおり後続会話を終えてからとする。`base.md`が「どうして分かる？」より前に解錠を置く点は従来からの記述差であり、今回の音声試作で解錠時点を変更しない。

ドア解錠後と完了画面からもSYSTEMの履歴へ戻れるようにし、最終側の既読音声を任意再生できる。

## 代替案と影響

字幕のみの継続では耳による因果ループの回収を試せず、全面音声化は試聴前の範囲を広げすぎるため採用しない。3場面以外は字幕のみとし、主要7問、真相、結末、開示順、進行schema v4を維持する。実行時TTS・マイク・バックエンドは追加しない。音声の有無や失敗で進行を止めず、試聴結果と実際の検証は`docs/progress.md`へ記録してから拡大を判断する。
