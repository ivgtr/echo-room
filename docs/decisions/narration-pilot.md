# 未来側の全発言を同じ声でつなぐ

[Issue #21](https://github.com/ivgtr/echo-room/issues/21)。2026-10-02の3場面試作から、2026-10-03のA80採用と依頼者の指示により、UNKNOWNを含む未来の自分の全発言へ拡大する。

## 決定

発話対象は`base.md`、受け入れ条件は`requirements.md`の11章、単一Sound Manager・静的WAV取得・設定互換性は`technical-design.md`の10章・12章を正本とする。音源の制作条件は`audio/voice/README.md`へ集約する。

- 未来側の通常会話10行とPACKET 4本文を扱い、重複2本文を共有して12原音とする。採用済みの冒頭・本人判明2原音は一切変更しない
- 原案にある「分かってる。まだ説明できない。」を、通信配線の調査後の会話へ復帰する。新しい事情や答えは追加しない
- 未来側は本人判明後も同じ通信加工を保つ。現在側の発話は最終送信「……聞こえるか？」だけを明瞭な声にし、冒頭と同一ファイルを使う
- PACKETの音声は正しく修復した後に表示した行だけを再生する。先の行へ進む操作はいつでもでき、音声完了を進行条件にしない
- 履歴は表示済みの行だけを任意再生する。主人公の独白、SYSTEM、手掛かり資料、話者のない段階式ヒント、装置の計測データは音声化しない

最終再演の既存台詞とドア解錠順、主要7問、真相、結末、進行schema v4を維持する。再開時は従来どおり完了したチェックポイントから履歴を復元し、自動で再発話しない。#15/#17/#18の残りの画面・装置演出はこの変更に含めない。

## 代替案と確認

3場面に留める案は今回の拡大指示により置き換える。主人公まで全面音声化する案は、終盤まで正体を守るため採用しない。実行時TTS・マイク・バックエンドは追加せず、WAVは固定Git commitから取得する。字幕fallbackと取消を維持し、追加音源の機械検査、利用者の原音採用、ゲーム内mixの実聴取を区別して`docs/progress.md`へ記録する。
