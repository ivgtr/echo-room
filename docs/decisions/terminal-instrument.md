# 端末を一台の観測・制御装置として扱う

日付: 2026-09-06 / 対象: Issue #13

## 判断

四つの表示分類は台詞や謎との対応を保つため残すが、一般的なタブではなく筐体の表示切替キーにする。装置が観測できる値、操作中の波形・接続、確定した記録を同じ表示器で扱う。パズル完了数は設備名に言い換えて残さず、削除する。

現行端末の背景には隣接パネルの`gfx-close-010__on`が使われていた。既存の端末画像`gfx-close-008__off`の空の表示器を再利用し、画像の縦横比を保った接近構図にDOMを合成する。新規の画像・SVG・3D・依存ライブラリは追加しない。

## 状態と情報

- 進行の正解は既存XStateのまま。表示selectorは観測結果を導出するだけで、保存schemaを変更しない。
- 同じ接写中は現在のパズル一つを保持し、別の表示ではhiddenにする。hidden・inertな操作部はTab順と読み上げから除外する。非選択中は診断タイマーと自動送信を停止し、再表示時に入力を保持したまま再開する。閉じる・再開で途中操作までは復元しない。
- 職員証取得前の施設図、調査前の確定経路と時間差、復元前の本文、校正前の本人一致を先出ししない。所持品から読む配線図も未確定図を基本とする。
- 照合した時刻と波形、確定経路、復元PACKETは再読できる。時刻・波形の定義は照合画面と再読画面で共有する。
- 送信部は常に同じ場所にある。試験通過までは無効と理由を示し、通過後にカバーを開く。連続入力をUIと既存machine guardで抑止する。

## 操作と表示

Tab・Enter・Space、波形の左右キー、既存のクリック／タップによる直接操作を維持する。Fキーのショートカットは追加しない。小画面では外周を見切り、スクロール可能な表示器と固定操作部に分ける。表示器自体にもfocusでき、keyboardで長い記録を読める。

切替は既存の端末接続音と短い走査表示だけに留める。同じ表示の再選択では再生せず、音OFF・reduced-motionでも選択状態と送信可否を文字で読める。ゲーム進行を演出や音の完了待ちにしない。

## 検証

検証環境: Node 24.15.0 / npm 11.9.0。指定のPlaywright Chromium 151.0.7922.34はCDNの502・タイムアウトで取得できなかったため、検証用のChromium 149.0.7827.0（SwiftShader）を`tmp/`へ展開して使用した。リポジトリの依存や標準browser指定は変更していない。日本語表示は検証環境へNoto Sans CJK JPを追加して確認する。

今回追加した修正:

- 非表示の診断タイマー・自動送信を停止し、再表示時の入力維持と一度だけの送信をunitで検証する。
- 配線図の未確定候補と確定経路を読み上げでも区別し、東側コンクリート壁の説明と図を整合させる。
- PACKET復元で入力部が消えた後、確認操作へkeyboard focusを移す。断線状態は現在の接続から示し、過去の失敗数によるBROKEN表示を成功後まで残さない。
- 最終試験後のメッセージが端末背後に隠れるpointer/touchの不具合を修正する。読了まで接写scopeをhidden・inertにし、表示器へfocusを戻す。
- 横幅650px以下で表示切替キー・送信状態の文字を大きく保つ。
- 古いSYSTEMタブへの初期focus期待、設定詳細から直接RESUMEするテスト、動き軽減と文字送り音の期待の矛盾を現行操作へ修正する。調査演出は壁時計の3秒延長を廃止し、Playwright時計で実際の380ms遷移を検証する。
- 検証出力を`tmp/`へ集約し、lint/formatから一時成果物だけを除外する。テストの削除・skip・無条件retryは行わない。
- `a928920`の全件実行で、選択済み配線buttonのCSS文字装飾がaccessible nameへ混入する回帰を検出した。接続状態は保持されていた。文字を持たない円形装飾へ修正し、厳密なbutton名と選択状態の検証は維持する。修正後の該当E2E 1件は成功した。失敗を含む初回実行は21件目で停止し、修正HEADで全件を再実行する。
