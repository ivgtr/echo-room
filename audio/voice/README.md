# 未来側の合成音声

Irodori-TTS / Irodori-v4.1-Smallで制作した、架空の設備保守担当者の声です。実在人物の録音・声の模倣は使用していません。

未来側の通常会話10行と、修復後のPACKET 4本文を12本の原音で扱います。同じ本文は原音を共有し、主人公の独白や話者のないヒントは読み上げません。

- `first-contact.wav`：採用済みの「……聞こえるか？」。冒頭、PACKET 01、最終送信は**同一の原音**です
- `identity.wav`：採用済みの「20分後のお前だ。」。声紋照合の確認後だけ再生します
- 新規10本：同じ合成参照、80 stepsで未来側の残りの台詞を生成しました。対応する字幕・合成入力・seed・checksumは[provenance.json](provenance.json)に記録しています
- `reference.wav`：同じ声を再制作するための合成参照。ゲームからは取得・再生しません

48kHz mono PCM16の生成原本を保存しています。採用済みの2原音と参照音声のbytesは変更していません。アプリは`src/audio/voiceManifest.ts`の固定Git commit URLから必要なファイルだけを取得します。`public/`へのコピーやアプリへのimportはせず、通信加工と音量調整は単一Sound Managerで再生時だけ行います。

再生対象12本は合計34.80秒 / 3,341,736 bytes、制作参照を含むGit内WAVは4,543,734 bytesです。

## 制作・確認

モデル・コードの固定revision、caption、seed、checksum、機械検査の範囲は[provenance.json](provenance.json)、利用条件と制作ツールの表示は[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)を参照してください。

2026-10-03に利用者が試聴して採用したA80の2原音を基準にしています。新規音源のASRと波形境界検査は、発話の自然さや余分な短い声がないことを保証する試聴ではありません。新規音源の実聴取、ゲーム内mix、iOS Safariは未確認です。

新規10本は全文・短い語尾のASRと波形境界を検査し、問題を検出した5本は再生成しました。全編認識にも「してる／している」「よし／よーす」「文／分」などの曖昧さがあり、全文の完全一致や全音源の実聴取済みは主張しません。

SilentCipher埋込は有効です。採用済みの短い2台詞では完全なpayload復号ができておらず、新規10本では完全なpayload復号を確認しました。制作参照では完全復号を確認しています。
